### 1/ (main)

I open-sourced **Grok Desk** — a local visual desk for Grok Build.

Not a terminal. Not another chat skin.

Electron + phone PWA over `grok agent stdio` (ACP): multi-agent pool, skills, MCP, plugins, workflows, plan mode, question cards, worktrees.

https://github.com/johnatfreecoffee/grok-desk

### 2/

It drives your real Grok CLI login on localhost — no Desk cloud backend.

Mac always-on via launchd. Same UI on phone over Tailscale + optional Web Push.

MIT. Clone → `npm install` → `npm start` → http://127.0.0.1:8787

### 3/

PRs welcome. Especially remaining gaps + hard mobile UX.
